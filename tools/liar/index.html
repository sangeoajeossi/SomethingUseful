라이어 게임

게임 방법
  1. 모두 같은 단어를 받지만, 라이어만 비슷하지만 다른 단어를 받아요.
  2. 기본으로는 라이어에게도 라이어라고 알려 주지 않아요. 토론하면서 스스로 눈치채야 해요. (설정에서 알려주기로 바꿀 수 있어요.)
  3. 돌아가며 단어에 대해 한마디씩 하고, 토론한 뒤 라이어 같은 사람을 투표로 뽑아요.
  4. 라이어를 전부 찾으면 시민 승리. 남은 라이어가 남은 시민만큼 많아지면 라이어 승리.
